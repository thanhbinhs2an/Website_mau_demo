# Website mẫu demo

Hai website mẫu demo thể hiện năng lực thiết kế website giới thiệu công ty và
trang danh mục sản phẩm. Đây là mẫu demo, không phải dự án của khách hàng thật.
Tên công ty, sản phẩm, giá và liên hệ trong trang đều là dữ liệu mẫu.

## Cấu trúc

Mỗi website nằm trong một thư mục riêng, gồm code tách riêng từng phần:

- `index.html` — nội dung và cấu trúc trang
- `style.css` — giao diện, màu sắc, bố cục
- `script.js` — bộ lọc, tìm kiếm, giỏ báo giá, form
- `images/` — hình ảnh minh họa của trang

không cần cài đặt gì thêm.
